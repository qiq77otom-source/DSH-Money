dsh余额 - DeepSeek 余额悬浮窗（原生 C 版）
==========================================

程序说明
--------
DeepSeek余额悬浮窗.exe   原生 Win32 / GDI+ 程序，约 97 KB
                         双击请求管理员权限（UAC），确认后运行
config.ini               API key、刷新间隔、窗口位置等配置
API Key 请在config.ini中添加，否则不会正常显示

功能
----
- 无边框半透明悬浮窗，深色 / 浅色 / 跟随系统
- 余额数字滚动、消费飘字与抖动动画
- 展开详情：充值余额、赠送余额、今日消费、账户状态、近 7 日柱状图
- 拖动移动、位置记忆、置顶、双击刷新
- 托盘图标：左键显示悬浮窗，右键打开设置菜单
  （Windows 11 若收进溢出区，可拖到任务栏常显）
- 单实例运行；开机自启（计划任务最高权限，登录无 UAC）

开机自启
--------
计划任务：DeepSeekBalanceFloat
- 登录后延迟 8 秒启动
- 最高权限运行，不会弹 UAC
- 任务指向本文件夹中的 exe

卸载
----
运行“卸载并清理.cmd”，按提示确认。脚本会：
- 结束正在运行的悬浮窗
- 删除计划任务 DeepSeekBalanceFloat
- 删除 Startup 残留、临时日志、config.ini、balance_stats.json
- 删除旧版 Python 备份目录
- 删除整个 dsh余额 文件夹及脚本自身

该操作不可恢复。运行前请确认不再需要 config.ini 中的 API key。

注意
----
- 不要移动或重命名本文件夹，否则计划任务路径会失效。
- 移动后请在新位置双击 exe，并在托盘右键菜单把“开机自启”关闭再打开一次。
- config.ini 内含 API key，请不要把本文件夹直接发给别人。
